Model Context Protocol (MCP) Server

Connect Claude Desktop, Cursor, Cline, or any MCP client to search notes, query handwriting OCR, inspect your document library, and retrieve tasks.

Local Claude Desktop Configuration (claude_desktop_config.json): 
{
  "mcpServers": {
    "remarkable": {
      "command": "python",
      "args": ["-m", "rmcompanion.mcp.server"]
    }
  }
}
Remote Network Client (Cursor / Cline / Windsurf / LibreChat): 
{
  "mcpServers": {
    "remarkable": {
      "url": "http://127.0.0.1:8099/mcp/sse"
    }
  }
}

Connects directly over your local network/Wi-Fi using Streamable HTTP / Server-Sent Events. Replace the host with your companion server's IP if different.

Claude Desktop over Network via SSH Bridge (Recommended): 
{
  "mcpServers": {
    "remarkable-remote": {
      "command": "ssh",
      "args": [
        "user@HOSTNAME",
        "docker", "exec", "-i", "rmcompanion", "python", "-m", "rmcompanion.mcp.server"
      ]
    }
  }
}

Claude Desktop only accepts command transports. This bridges stdio over SSH without needing node or proxy packages installed.

Alternative: Claude Desktop via mcp-proxy (Node / NPX): 
{
  "mcpServers": {
    "remarkable-remote": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-proxy",
        "http://127.0.0.1:8099/mcp/sse"
      ]
    }
  }
}
Direct Endpoint URL: http://127.0.0.1:8099/mcp/sse
